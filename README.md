# FitPulse — Intelligence Opérationnelle pour le Retail Mode

Plateforme d'analyse qui transforme le parcours client en magasin mode en décisions opérationnelles temps réel.

PwC Challenge Étudiants 2026

## Lancer le prototype

pip install streamlit pandas plotly numpy

python fitpulse_engine.py
streamlit run fitpulse_dashboard.py

Le moteur génère 500 scans simulés et produit automatiquement des alertes et KPIs.
Le dashboard affiche les résultats sur localhost:8501.

## Ce que le prototype démontre

- 13 alertes réassort (dont 3 critiques)
- 2 articles problématiques détectés
- 3 pics d'affluence identifiés
- 21 sous-commandes tailles révélées
- 39 décisions générées automatiquement
